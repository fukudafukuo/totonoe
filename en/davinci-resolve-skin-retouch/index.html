How to smooth skin in DaVinci Resolve (free version and Studio)

This guide shows how to smooth skin in DaVinci Resolve with Color page tools: a Qualifier to pick the skin, a Power Window to limit the area, and Mid-tone Detail or the Blur palette to soften it. It also explains which face effects are Studio-only, and where a plugin can help.

The steps in section 1 use features that the DaVinci Resolve 21 Reference Manual does not mark as Studio-only. Features can differ between versions, so check each tool in your own copy of Resolve.

Sources: the DaVinci Resolve 21 Reference Manual and the official Studio page, checked November 14, 2026 (links at the end). I have not used DaVinci Resolve Studio, so the Studio section is based on those documents only.

1. Smooth skin with the standard tools

  1. Add a node. Open the Color page and add a new node for the skin adjustment, so you can switch it off to compare.
  2. Pick the skin with the Qualifier. Sample the skin with the Qualifier's eyedropper, then adjust the Hue, Saturation and Luminance ranges. The manual gives keying an actor's skin color to soften it selectively as an example of what a Qualifier is for.
  3. Check the selection with Highlight. Turn on Highlight to see which areas are selected. Look for hair, lips, clothing or a background of a similar color that has been picked up, and narrow the ranges until it is mostly skin.
  4. Limit the area with a Power Window (optional). If other areas are still selected, draw a Power Window around the face. The manual says windows limit the area of an adjustment and that the tracker can make a window follow the subject, so track the window if the person or the camera moves.
  5. Soften the skin. Use one of these two methods, or both lightly:
    • Mid-tone Detail (MD). It is in the color wheels palette and runs from −100 to +100. According to the manual, a negative value softens areas with little detail, while areas with a lot of detail stay. Start with a small negative value.
    • Blur palette. The Blur palette has Blur, Sharpen and Mist. The manual says the range can be limited with an HSL Qualifier, a window or a matte, so in this node the selection from steps 2 to 4 applies. Use a small amount so that skin texture stays.
  6. Check in motion. Switch the node on and off, and play the clip. If the selection changes from frame to frame, the effect can appear and disappear, so go back to the Qualifier ranges and the window.

The manual lists Spatial NR and Soften and Sharpen as Studio-only, so this guide does not use them.

2. Studio-only face effects

In the DaVinci Resolve 21 Reference Manual, these ResolveFX are marked “Studio Version Only”: Face Refinement, Beauty, Blemish Removal, Face Age Transformer and Face Reshaper.

  • Face Refinement detects and tracks faces and builds a skin mask automatically. It adjusts skin texture (Skin Texture), eyes, lips, teeth, cheeks, forehead, chin and more, each separately. When a shot has several faces, you choose the target.
  • Beauty smooths detail above a certain size and keeps fine detail such as pores. Its modes are Automatic, Advanced and Ultra Beauty (Ultra Beauty is a mode inside Beauty, not a separate effect). The manual suggests limiting its range with a qualifier or similar.
  • Blemish Removal uses AI to remove small spots and marks. Its only control is Strength.
  • Face Age Transformer and Face Reshaper are listed as AI tools in the DaVinci Resolve 21 New Features Guide.

3. A plugin option on Mac: Totonoe Skin Retouch

If you want skin to be found and smoothed in one effect, you can use a plugin. Totonoe Skin Retouch is my OpenFX plugin for DaVinci Resolve. It finds skin by color (there is no face detection), and Smoothing, Texture, De-Shine, Blemish and Redness / Paleness work on the detected skin. It applies to everyone with a similar skin tone, so use a Resolve window or mask when you want only one person.
